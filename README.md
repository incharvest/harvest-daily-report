# デイサービスハーベスト 日報管理システム

マッサージ・リハビリ重視型デイサービスハーベストの日報管理Webアプリケーションです。

## 機能

- 職員ログイン（パスワード認証）
- 日報の作成・編集・削除
- 音声入力による報告内容の入力
- 写真の撮影・添付
- 日報の検索・フィルタリング
- 全職員の日報まとめ表示
- 日報のダウンロード・印刷
- 共有まとめ機能
- 管理者機能（職員管理、データ管理）

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番ビルド
npm run build
```

## 技術スタック

- React 18
- Vite
- Tailwind CSS
- Lucide React (アイコン)
- Web Speech API (音声認識)
- MediaDevices API (カメラ)
